# 🎙️ AI语音简报助手

语音直接转文字，自动生成中英双语简报。支持实时录音和文件上传，一键导出 Markdown 文档。

## 功能特点

- 🎙️ **实时录音**：直接在浏览器中录音，自动转写
- 📁 **文件上传**：支持 MP3、WAV、M4A、WEBM、OGG，最大 200MB
- 🤖 **智能分类**：AI 自动识别简报类型（会议纪要 / 客户拜访 / 工作日报 / 其它摘要）
- 🇨🇳 **中文简报**：结构化 Markdown 格式，可在线编辑
- 🇬🇧 **英文版本**：按需生成，支持编辑后导出
- 📋 **一键复制**：iOS PWA 原生复制，无需剪贴板权限
- 💾 **下载导出**：支持 `.md` 文件下载

## 技术栈

- [Streamlit](https://streamlit.io/) — Web 应用框架
- [SiliconFlow](https://cloud.siliconflow.cn/) — API 服务（转写 + 生成）
- [FunAudioLLM/SenseVoiceSmall](https://huggingface.co/FunAudioLLM/SenseVoiceSmall) — 语音转文字模型
- [DeepSeek-V3](https://www.deepseek.com/) — 简报生成 & 翻译模型

## 快速开始

```bash
pip install -r requirements.txt
streamlit run app.py
```

在 `.streamlit/secrets.toml` 中配置 API 密钥：

```toml
SILICONFLOW_API_KEY = "sk-xxxxxxxxxxxxxxxx"
```
